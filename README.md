## 💻 Quick Start (Node.js)

### Prerequisites
- Node.js (v18 or higher): [https://nodejs.org/](https://nodejs.org/)
- npm or bun

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/pharmastar-app-pro.git
cd pharmastar-app-pro

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Or start full-stack Node.js server
npm run start
```
The app will be accessible at `http://localhost:3000`.
